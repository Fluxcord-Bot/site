## Bridging a voice channel

 <Aside type="danger" title="Important Notes">
  Fluxer does not currently support end-to-end voice encryption, that means
  Fluxcord will bridge your Discord VC **unencrypted**. Aside from that, to bridge
  voice data, **it will decrypt** DAVE-encoded data to be sent to Fluxer.

Please make sure you have discussed this clearly with your server members,
and add an easy-to-find disclaimer about the bridge.

</Aside>

 <Steps>
 1. Firstly, run `fc!bridge setup` on the voice channel you want to bridge, on either side.
    <Aside type="note">
    Change `fc!` to your instance's prefix if `fc!` did not work (e.g. if you're using Fluxcord on FluxFur, use `fcfur!bridge setup`)
    </Aside>
   <Aside type="tip">
     Bridging a already bridged channel? Just run `fc!bridge setup` again.
   </Aside>

2.  Fluxcord should reply to you with a command to put on the other side. Copy it and send it on the voice channel you want to bridge to.

3.  Congratulations, your voice channel is now bridged! Join either side and you should hear the other side.
    <Aside type="note">
    If you think your server usually have multiple voice channels active at the same time, you can invite
    additional voice bridging bots below. This is optional as the main bot is also capable of voice bridging.

## Bridging a forum channel
 <Steps>
 1. Firstly, create a temporary forum thread on both sides.
    <Aside type="note">
    Using a existing forum thread will also work.
    </Aside>
    <Aside type="tip">
    Bridging a already bridged channel? Just run `fc!bridge setup` again.
    </Aside>

 2. Then, run `fc!bridge forum` on the forum thread, on either sides.
    <Aside type="note">
    Change `fc!` to your instance's prefix if `fc!` did not work (e.g. if you're using Fluxcord on FluxFur, use `fcfur!bridge forum`)
    </Aside>

2.  Fluxcord should reply to you with a command to put on the other side. Copy it and send it on the thread on the other side.

3.  Congratulations, your forum channel is now bridged! Existing threads can be bridged by just chatting on them.
   </Steps>
